# D231-WebDesign-Devoir2

## 📌 Description

Ce projet consiste en la réalisation d’un site web en HTML et CSS consacré à la Ligue des Champions.
Il présente l’histoire de la compétition ainsi que les clubs les plus emblématiques.

## 🗂️ Structure du site

Le site est composé de trois pages :

- **index.html** : page d’accueil et présentation du site
- **histoire.html** : évolution de la compétition depuis 1955
- **clubs.html** : clubs légendaires (Real Madrid, Bayern Munich, PSG, etc.)

## 🎨 Technologies utilisées

- HTML5
- CSS3
- Deux feuilles de style :
  - `screen.css` (affichage écran)
  - `print.css` (version imprimable)

## 🌐 Déploiement

Le site est hébergé avec **GitHub Pages**, ce qui permet un accès public sans publicité.

👉 Accéder au site :
https://christmknd.github.io/D231-WebDesign-Devoir2/

## 🧠 Objectif pédagogique

Ce projet avait pour but de travailler :

- la structuration d’un site web en plusieurs pages
- l’utilisation de feuilles de style adaptées au support (écran / impression)
- le déploiement d’un site statique en ligne

## ℹ️ Remarque

Ayant déjà des bases en développement web, ce projet a surtout permis de consolider mes connaissances en HTML/CSS et de revoir certaines bonnes pratiques.
